# Triagem de contrato — checklist da Drap

> Saída SEMPRE começa com: **"RASCUNHO PARA REVISÃO HUMANA — não é parecer

> decide é o dono (e advogado, quando preciso).

## Formato do parecer

- Uma linha por cláusula: ✅ ok | ⚠️ negociar | 🚩 bandeira, com o porquê
  em uma frase.
- Fecha com: os 3 pontos a negociar primeiro, em ordem de dano.
